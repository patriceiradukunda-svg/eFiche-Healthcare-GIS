MATCHING METHODOLOGY
───────────────────────────────────────

Algorithm:    Weighted similarity scoring
Match Criteria: Name, Proximity, Facility Type

Scoring:
  Score = (Name × 0.4) + (Proximity × 0.4) + (Type × 0.2)
  
Name Similarity:
  Exact match          → 1.0
  Substring match      → 0.8
  No match             → 0.0
  
Proximity (lat/lon distance):
  Within 5km (~0.05°)  → 1.0
  Beyond 5km           → 0.0
  
Type Similarity:
  Exact type match     → 1.0
  Related type         → 0.5
  Unrelated type       → 0.0

Threshold:   Score > 0.7 = considered matched

Result:      31 unmatched eFiche + 7 unmatched OSM = 131 total unique
